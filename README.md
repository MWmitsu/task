# 📌 やること（Web版）— iPad・スマホ・どのブラウザでも

Windows常駐ウィジェットと**同じ感覚で使えるタスク管理**を、**iPad（Safari）やスマホ、どのPCのブラウザ**でも動くようにしたWeb版です。インストール不要・追加費用なし・データは端末の中だけ（ブラウザの保存領域）＋お好みでクラウド同期。

**公開URL： https://mwmitsu.github.io/task/ （PWA：ホーム画面に追加するとアプリのように・オフラインでも起動）**

`index.html` 単体でも動きますが、ホーム画面アプリ化・オフライン起動には同じフォルダの `manifest.webmanifest` / `sw.js` / `icon-180.png` / `icon-512.png` が必要です（公開URLにはすべて含まれています）。

## iPadで使う（おすすめ：公開URLをホーム画面に追加）
1. Safariで **https://mwmitsu.github.io/task/** を開く
2. **共有ボタン → 「ホーム画面に追加」**
3. ホーム画面のアイコン（白いチェックマーク）から、**アプリのように全画面**で起動。Service Workerにより**オフラインでも開けます**

> ファイルとして配る場合（`index.html` をOneDrive/AirDrop等で渡す）も使えますが、`file://` ではGoogleログイン・オフラインキャッシュは無効です。データはその端末内に保存されます。履歴消去で消えるので、大事なときは「⇅ → JSON書き出し」でバックアップを。

## クラウド同期（複数端末で自動・麻雀アプリと同じ方式）
右上「⇅」→「**🔑 Googleでログイン**」すると、**iPad・PCのブラウザなど複数端末で自動同期**されます（麻雀スコアアプリと同じ Firebase 方式）。
- ログイン中は、編集すると自動でクラウドへ保存され、他端末にもすぐ反映（`onSnapshot`）
- ログイン時の突き合わせは、この端末が**最後に同期したクラウド文書の時刻**（`tw_cloud_seen_at`）と**最後に同期した時点のローカル内容の署名**（`tw_synced_sig`）で判定：同内容→何もしない／クラウドだけ変わった→クラウドを採用／この端末だけ変わった→この端末を送信／**両方が変わった（真の競合）ときだけ**「どちらを使うか」を確認（選択は記憶しない＝毎回選べる。旧版の `tw_cloud_choice` は廃止）。ログアウトで記憶を消去。クラウド側でタスクが半分未満に激減している場合は、適用前にローカルを端末内へ退避（`tw_protect_…`）して警告
- ログイン直後の**突き合わせ中はローカル→クラウドの送信を保留**し、空データでの上書きを防止（認証世代ガード付き）
- **編集シートを開いている間はリモートの反映を保留**し、閉じた直後に反映（入力中の取りこぼし防止・他端末の追加も捨てない）
- 同期に失敗しても次の変更時に自動で再送（失敗はトーストで通知）。「同期済み」の記録（`tw_cloud_seen_at`／`tw_synced_sig`）は**クラウドへの書込みが成功してから**行うため、失敗した未送信の変更が次回ログイン時の突き合わせでクラウドに上書きされることはない
- オフラインや未ログインでもローカルだけで普通に使えます（同期だけ止まる）
- ※ `file://`（ファイル直接開き）ではGoogleログイン不可 → **公開URL https://mwmitsu.github.io/task/** で使ってください

### 🔄 Windows版との実データ同期（共有ファイル `taskweb-sync.json`）
Windows常駐版とは、共有ファイル経由でタスク・完了数・メモ・出退勤・完了履歴を同期できます（ブラウザの仕様上「完全自動」は不可のため、ファイル受け渡しが現実解）。

- **Windows版**：保存のたび `taskweb-sync.json` をフォルダ（OneDrive配下）へ**自動で書き出し**、起動時に**自動で取り込み・マージ**。トレイ「🔄 Web版と同期」で手動更新も可
- **Web版**：⇅ →「📥 同期ファイルを取り込み（widgetから）」で `taskweb-sync.json` を選択（重複はマージ）、「📤 同期ファイルを書き出し（widgetへ）」でファイル化 → Windows版のフォルダへ置けば次回起動で取り込み
- マージ方針：タスクは**本文一致で重複除外して追加**し、本文一致の既存タスクは **`updatedAt` が新しい側の同期対象フィールド**（完了・締切・分類・備考・優先度・見積・タグ・繰り返し・サブタスク・アラーム・完了日 `doneAt`）を採用（v1.6.0〜。計測中の経過時間や追加時刻は端末ごとに保持。相手が旧版で `updatedAt` を持たない場合は従来どおり追加のみ）。同名タスクが複数あるときは**本文＋出現順**で対応付け、取り込み先は編集中でない最初の1件のみ。相手の「完了」を取り込んだとき計測中なら作業時間を確定して停止。完了数は**今日〜6日前の7日間は完了履歴の非取消行の件数**（それより古い日は最大）、出退勤は**欠落日を追加**、完了履歴は**（日付|時刻|本文）で1行に統合し、取消/復活が新しい側の状態を採用**（`at`＝最後に状態が変わった時刻。相手が古い版で `at` を持たない場合は取消優先）、メモは**空のとき採用**（=どちら向きでもデータが消えない安全側）
- **完了日 `doneAt`**（v1.8.0〜・widget と同一契約）：完了した営業日 'yyyy-MM-dd'（未完了は ''）。SYNC_FIELDS の末尾に追加（署名・コピーの対象）。チェック時に営業日の今日を刻印、取消・繰り返しの繰り越しで ''、CSV 取り込みの完了行は ''（完了日不明）。load/applyRemote で done かつ doneAt 空のタスクへ completionLog の本文一致・(date,time) が最大の非void行の date をバックフィル（配列順に依存せず Windows版と同じ答え）（署名再構築の前＝updatedAt は刻印しない＝同期の往復を起こさない）。「今日」タブは「完了済みで完了日が今日より前（不明 '' 含む）」を除外（他タブ・完了を隠す・完了数・ストリークは変更なし。当日完了は終日表示・取消で戻る）。旧版相手は doneAt 無し→'' で受け、同じ payload の completionLog からフォールバックで解決
- 完了チェックの取消は完了履歴の当該行を消さず `void: true`＋`at`（取消時刻）を付ける（同期相手の古い行から復活しない・同じ分に再チェックすると同じ行が復活して1件として数える・集計/日報/履歴/グラフは取消行を数えない）
- 削除・改名は**墓標（`deleted`）**で相手側へ伝わる（14日で失効）。編集シートの🗑削除・本文の変更も同様
- 手動分類（`customCats`）は**キーで突合して無いものを追加**（自分の名前・色は維持）。ウィジェット側の rgb 配列も `#rrggbb` に変換して受け付ける。分類の削除は墓標 **`deletedCats: [{key, at}]`**（60日で整理・最大100件）で相手側へ伝わり、相手の customCats に残っていても復活しない（中のタスクは「通常」へ）
- 同期対象は**タスク中心**（設定・テンプレ等のアプリ固有UI設定は各アプリで独立）。例外として**日付の切り替え時刻**は同期docのトップレベル `dayStart`（0〜12）／`dayStartAt`（最後に変えた時刻・UTC ISO）で3アプリに伝わり、`dayStartAt` が新しい側を採用（同じ・古い・無しは何もしない）

## 仕組み（技術メモ）
- 本体はHTML+CSS+JSの単一ファイル（`index.html`）。フレームワーク不要。`localStorage` に保存（キー `taskweb-data-v1`）
- PWA用に同じフォルダへ `manifest.webmanifest`・`sw.js`（Service Worker）・`icon-180.png`・`icon-512.png` を同梱
  - Service Workerは**同一オリジンのアプリ本体だけ**をキャッシュ（オフライン起動用）。Firebase等の別オリジン通信は一切触らず同期を壊さない設計
  - キャッシュを更新したいときは `sw.js` の `CACHE` 名（例 `taskweb-v2`）を上げる
- CSVは Windows版 `Export-Tasks-Csv` と同じ列順（text,done,cat,priority,due,estimate_min,tags,note,**repeat,subs**）・タグは `|` 区切り・先頭にBOM。引用符内の改行も保持。**繰り返し**はラベル（なし/毎日/平日/毎週）、**サブタスク**はタブ区切り＋各項目の先頭1文字が完了フラグ（1=完了/0=未、例 `1牛乳⇥0パン`）で本文に `|` や `✓` が含まれても壊れません — Windows版と相互運用可。旧列だけのCSVも取り込み可
- JSON取り込みは Web版の書き出しと Windows版 `widget-data.json` の両方を受け付け（分類はキー/ラベルどちらも解釈）。`hideDone`（完了を隠す）も往復
- ローカル確認用サーバ：`powershell -ExecutionPolicy Bypass -File serve.ps1 -Port 8190`（iPadで使うだけなら不要）
- デプロイ：このフォルダが GitHub リポジトリ `MWmitsu/task` のソース。`git add -A && git commit && git push` で https://mwmitsu.github.io/task/ に反映（Pagesビルド後、CDNの404キャッシュが数分残ることがある）
